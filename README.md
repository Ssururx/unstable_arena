# Unstable Arena

A Roblox physics-survival brawler built with Luau and Rojo.

## Prototype goal

Players fight on an irregular slab platform suspended over a void. Player movement shifts the platform's balance, crowded slabs accumulate stress, and weakened slabs crack before breaking away.

## Local workflow

1. Clone this repository.
2. Open the folder in Visual Studio Code.
3. Start the Rojo project.
4. Open a Baseplate in Roblox Studio.
5. Connect the Rojo 7 Studio plugin.
6. Press Play.

All prototype geometry is generated by server code. No manual Studio models are required for the first milestone.
